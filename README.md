# Osu-HackPad
Hackpad for blueprint run by Hack Club

# Features
- 4 keys used for 4K osu!mania and osu!
- 0.91 inch OLED display to display recent keypresses
- KMK support

# BOM
- 4x Cherry MX Switches
- 4x DSA Keycaps
- 1x 0.91" 128x32 OLED Display
- 4x M3 screws
- 4x M3x5x4 Heatset inserts
- 1x Case
- 1x Plate
- 1x XIAO RP2040
